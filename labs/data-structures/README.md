# Data Structures

Core data structure implementations from lecture examples:

- `binary_tree.py` — binary search tree with insert and in-order traversal.
- `linked_list.py` — singly linked list with a max-size guard and thread-safe append.
- `avl_tree.py` — self-balancing AVL tree with insert, delete, and search.
- `graph_v1_basic.py` — adjacency-list graph, minimal validation.
- `graph_v2_validated.py` — same graph structure with added input validation and duplicate-edge handling (GenAI-assisted refactor of v1).
