# Course Lab Environment Guide

Notes on the platform's built-in Python Lab Environment for the *Generative AI for Software Development* specialization (DeepLearning.AI / Coursera).

## Using the lab alongside lectures

1. **Follow along**: as lectures introduce Python concepts, code snippets, and files, the Python Lab Environment is where you test them in real time.
2. **Download lecture files**: some lectures provide downloadable files (scripts, datasets, etc.) via the folder icon in the top-left corner of the lab.
3. Downloaded files are available in the lab workspace to open, edit, and run.

## Getting started

Click **JupyterLab** in the top-right corner. A blank notebook is provided to paste and run LLM-generated code, or create a new one via the blue **+** button (Notebook section → Python 3).

## This repository's workflow

Graded labs still require the platform's hosted grader (see root `README.md`), but exploratory work and downloaded lecture files are developed locally and mirrored here for reference and portfolio purposes.
